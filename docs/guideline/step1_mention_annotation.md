# Step 1：場所参照表現のスパン認定・種別ラベル付与

## ラベル定義

- `LOC_NAME`, `LOC_NOM`：地名・地形名
- `FAC_NAME`, `FAC_NOM`：施設名
- `TRANS_NAME`, `TRANS_NOM`：乗り物名
- `LINE_NAME`, `LINE_NOM`：路線名
- `LOC_OR_FAC`：地名・施設名の両方に該当し得る総称的な表現
- `LOC_ORG`：組織名として使われている地域名（国名・自治体名）
- `FAC_ORG`：組織名として使われている施設名
- `DEICTIC`：指示表現
- `TENTATIVE`：作業用の臨時的なラベル

## アノテーション基準

カバレッジを重視し、迷う場合は `TENTATIVE` ラベルなどを利用しつつ広めに付ける。後のステップで、必要に応じ、割り当てたラベルの変更や削除を行ってもよい。

1. **固有表現カテゴリ**の固有名・一般名に対するラベル付与・不付与
    - 基本方針
        - 関根の拡張固有表現階層の [1.5 地名](http://liat-aip.sakura.ne.jp/ene/ene8.1/definition_jp/html/enedetail.html#1_5) のサブカテゴリに該当する固有名には `LOC_NAME`、一般名には `LOC_NOM` を付与し、同様に [1.6 施設名](http://liat-aip.sakura.ne.jp/ene/ene8.1/definition_jp/html/enedetail.html#1_6) のサブカテゴリに該当する固有名には `FAC_NAME`、一般名には `FAC_NOM` を付与する。ただし、別途言及がある場合には本ガイドラインを優先する。特に、路線名には `LINE_NAME` か `LINE_NOM` を付与し、乗り物名には `TRANS_NAME` か `TRANS_NOM` を付与する。
        - 多くの場合、人が区画を決めた地域と、自然物は通常 `LOC_NAME` か `LOC_NOM` となり、人工的な場所・施設・ランドマークは主に `FAC_NAME` か `FAC_NOM` となる。ただし、自然物であっても、小さい物質や、人が乗り上げないような形状のものは、ランドマーク（つまり施設）と考えてよい。なお、場所・施設の管理方針上、立入禁止となっていることはラベルの種類に影響しない。
        - 場所か施設か明確に分類しがたい場合は、主観的な判断で決める。
    1. GPE・FOE
        - GPE (Geopolitical Entity) は「政治的機能を持つ国・地域・自治体の名前」、FOE は「組織名としての属性を持つ施設の名前」。
        - 文脈により国・地域・自治体を表していると判断できる場合には `LOC_NAME` か `LOC_NOM`、 施設を表していると判断できる場合には `FAC_NAME` か `FAC_NOM` を付与。組織名としての言及と判断できる場合には `LOC_ORG`（GPE の場合）または `FAC_ORG`（FOE の場合）を付与。文脈によらず常に組織になるようなものには何も付与しない。
    2. 地域名
        - `LOC_NAME` か `LOC_NOM` を付与する。国を超える広域地域名（例：「北アフリカ」「北極」）にも付与する。
    3. 地形名
        - 通常は `LOC_NAME` か `LOC_NOM` を付与する。ただし、地形自体を指している場合の他に、メトニミーによりその地形に関連する施設を指している場合がある。言語表現自体が何（地名・地形または施設）を指すものかという点をまず考慮し、次に文脈を含めた場合に何を指しているかを考慮し、最終的なラベルを判断する。
        - たとえば、「富士山」は `LOC_NAME`。「月ヶ瀬温泉」は温泉地を指していれば `LOC_NAME`、温泉施設を指していれば `FAC_NAME` を付与する。
        - 「森」「池」「平野」「湿原」「島」のような一般名には `LOC_NOM` を付与する。
    4. 海洋名・湾名
        - `LOC_NAME` か `LOC_NOM` を付与する。固有名を持つ海域や湾の名前だけでなく、不定の「海」にも付与する。
    5. 郵便住所
        - 住所や郵便番号で特定可能な地点・地域に対し、`LOC_NAME` を付与する。
        - たとえば、「奈良県生駒市高山町8916番地の5」には全体に `LOC_NAME` を付与する。
    6. ダム名
        - `FAC_NAME` か `FAC_NOM` を付与する。[拡張固有表現](http://liat-aip.sakura.ne.jp/ene/ene8.1/definition_jp/html/enetree.html)の例を参照。
    7. 遺跡名
        - `FAC_NAME` か `FAC_NOM` を付与する。[拡張固有表現](http://liat-aip.sakura.ne.jp/ene/ene8.1/definition_jp/html/enetree.html)の例を参照。
    8. 交通施設名
        - `FAC_NAME` か `FAC_NOM` を付与する。[拡張固有表現](http://liat-aip.sakura.ne.jp/ene/ene8.1/definition_jp/html/enetree.html)の例を参照。空港名、港名、鉄道駅名、停車場名（バス停）、道路施設名（駐車場やパーキングエリア）などが該当する。
        - 考慮を要する例として、文脈から電車の行き先・駅名とわかる「[和歌山]行き」には `FAC_NAME` を付与する。
    9. 路線名
        - 拡張固有表現では施設名の下位カテゴリとなっているが、本作業では `LINE_NAME` か `LINE_NOM` を付与する。
        - たとえば、「近鉄奈良線」には `LINE_NAME` を付与する。
        - 自然物であっても、「淀川」のように線状の地形名等にも `LINE_NAME` を付与する。
    10. 乗り物名
        - 公共交通機関の種別や車両名に対して（交通手段として言及されている場合）`TRANS_NAME` か `TRANS_NOM` を付与する。
        - たとえば、「特急ひのとり」には `TRANS_NAME`、「電車」「新幹線」「バス」には `TRANS_NOM` を付与する。
    11. 部分施設名
        - 方針1：より大きな施設（全体施設）の敷地内に存在する施設（部分施設）については、敷地や建物として独立しているなど、独立性が高い場合にはラベルを付与する。建物の一部に当たる場合でも、全体施設と切り離しても独立した施設としての機能を持つ場合（旅館内の「ショップ」、ビル内の「レストラン」など）はラベルを付与する。
            - 「駐車場」→ `FAC_NOM`
            - 「観覧車」（遊園地の部分施設）→ `FAC_NOM`
            - 「別館」（旅館の部分施設）→ `FAC_NOM`
            - ショッピングモール内の店舗名（ショッピングモールの部分施設）→ `FAC_NOM`
            - 「風車」（風力発電所の部分施設）→ `FAC_NOM`
            - 「本殿」（寺社等の部分施設）→ `FAC_NOM`、「東金堂」（「興福寺」の部分施設）、「薬井戸」（「大神神社」の部分施設）→ `FAC_NAME`
                - 寺社などでは、敷地全体を「○○寺」「○○神社」と呼び、敷地内に複数の建物やランドマーク（信仰物）を含むことが多い。また、建物・ランドマークに固有名がついている場合と一般的な名称で呼ばれる場合がある。
        - 方針2：場所・施設の分離不可能な一部にあたるものや、建物の一部であって特に独立した施設としての機能を果たさないものは、付与対象外とする。
            - 階数：「2F」「5階」
            - 部屋：「部屋」「待合室」「フロント」「バスルーム」「内湯」
    12. 景勝地や信仰の対象として固有名が付いたランドマーク等
        - 固有名が付いた景勝地や信仰の対象物は、通常は場所・施設とみなされないカテゴリに当たる場合でも、ラベルを付与する。また、そのような固有名の付いた対象物を指す一般名詞句の場所・施設名にもラベルを付与する。
        - たとえば、「薬井戸」には `FAC_NAME`を付与し、「夫婦岩」や「巳の紙杉」もランドマークと捉えて `FAC_NAME` を付与する。これらのランドマークを指す「井戸」「鳥居」「岩」「杉」などにも `FAC_NOM` を付与する。
            - 「一の鳥居」は一般名詞で、`FAC_NOM`。
    13. 付与対象外とするもの
        - 天体名：「地球」やそれに準じる表現、「木星」などには付与しない。
        - アドレスその他：メールアドレスなどには付与しない。
2. **一般名詞で構成される場所・施設名**に対するラベル付与・不付与
    - 基本方針
        - 付与対象とする地名・施設名（`{LOC,FAC,LINE,TRANS}_NAME`）と同様のカテゴリ・粒度に相当する一般名詞句に対して、（文書中に現れる地名・施設名との共参照関係の有無にかかわらず）`{LOC,FAC,LINE,TRANS}_NOM` を付与する。
        - 例
            - 「森」「池」「平野」「湿原」「島」→ `LOC_NOM`
            - 「砂風呂」（指宿市で有名な砂蒸し温泉の施設を指す例）→ `FAC_NOM`
            - 「道」「橋梁」「水路」「川」→ `LINE_NOM`
            - 「海岸」→ `LOC_NOM` か。「海岸線」など線状の構造を意識した言及なら `LINE_NOM`もあり得る。
    1. 場所・施設を表す具体性の低い名詞を主辞とする表現
        - 場所・施設を表していると考えられる場合、広く付与対象とする。
        - 例
            - 「休憩施設」「公園施設」「休憩所」「観光案内所」「駐車場」→ `FAC_NOM`
            - 「休憩場所」「駐車場所」→ `FAC_NOM`
            - 「周氷河地形」→ `LOC_NOM`
            - 「名所」「観光地」「絶景ポイント」「ラムサール条約指定地」→ `LOC_OR_FAC`
                - 場所と施設両方が該当し得る表現。なお、これらは場所の属性を説明している状況も考えられる。
    2. 私的な場所・施設
        - 私的な場所・施設であっても付与対象とする。
        - 例
            - 「地元」→ `LOC_NOM`
            - 「我が家」「実家」「自宅」「職場」→ `FAC_NOM`
                - 上記のような極めて私的な施設や、著者の個人情報にあたる可能性が高いものには、後段ステップで共参照関係・地図リンク情報付与の対象外とする。
3. **指示表現**に対するラベル付与・不付与
    - 方針1：指示代名詞等（＋格助詞「の」）が地名・施設名にあたる名詞句を修飾する場合、（形容詞が名詞修飾する場合と同様に）指示代名詞等を除く地名・施設名をスパンとしてラベル `{LOC,FAC,LINE,TRANS}_{NAME,GENERAL}` を付与する。
        - 例
            - 「この[温泉]」「前者の[温泉]」→ `FAC_NOM`
            - 「こちらの[奈良健康ランド]」→ `FAC_NAME`
            - 「この[奈良]」→ `LOC_NAME`
    - 方針2：地名・施設名（の言語表現または実世界上の実体）を指す指示代名詞等の指示表現が、地名・施設名を修飾せず、別に独立した名詞句として出現する場合、指示表現自体にもラベル DEICTIC を付与する。
        - 例
            - 「[こちら]は…」「[前者]は…」「[こちら]にある温泉」「[ここ]奈良では」「[ここ]は奈良で」「[2軒目]は[こちら]へ。」→ `DEICTIC`
                - 上記例の「温泉」「奈良」などにも別途 `LOC_NAME` や `FAC_NOM` などのラベルを付与する。
4. **非正式名称で表された場所・施設名**に対するラベル付与・不付与
    1. 地域区分・施設種別を表す接辞等の脱落
        - 地域や施設を指していると文脈から判断できる場合、`LOC_NAME` や `FAC_NAME`を付与する。
        - 例
            - 「[神戸]に行きました」→ `LOC_NAME`
            - 「[京終]など難読な駅名」→ `FAC_NAME`
    2. 別名・通称名
        - 固有名・通称名として（多数の人の間で）定着している場合は、その名称全体をスパンとしてラベルを付与する。そうでない場合、全体として特定の場所・施設を指すなら、以下の構造にあたるものをひとまとまりにし、ラベルを付与する。
            - 名詞と格助詞「の」（古語「が」含む）からなる表現
        - 例
            - 「渡らずの橋」→ JR 城西駅付近にある橋の通称名として定着していると考え、全体にラベル `LINE_NAME` を付与する。
            - 「天国に一番近い島」→ ニューカレドニアのウベア島を指す通称名として定着していると考え、全体にラベル `LOC_NAME` を付与する。
            - 「日本最北端の地の碑」→ この名称で呼ばれる碑があるため、全体に `FAC_NAME` を付与する。
        - 反例
            
            最上級や序数等の表現によって概ね一つの地点・施設に定まる表現であっても、それが通称名として定着していると言えない場合は、構成要素のPOI表現にラベルを付与するにとどめる。
            
            - 「日本最北端の地」：（「宗谷岬」「弁天島」など）指している場所を絞ることはできるものの、通称名として定着しているものではないと考え、「[日本]最北端の[地]」というように「日本」に `LOC_NAME`、「地」に `LOC_NOM` を付与する。
            - 「本州最南端」：（「潮岬」など）指している場所を絞ることはできるものの、通称名として定着しているものではないと考え、「本州」に `LOC_NAME` を付与する。
    3. 誤った名称
        - 適切な地名・施設名が想定できる場合、それに応じたラベルを付与する。地図リンク情報付与時、正しい名称で検索した場合は注釈する。
        - 例
            - 「江の島児子ヶ淵」（「稚児ヶ淵」と思われる）→ `LOC_NAME`
5. **複合名詞的な場所・施設表現**に対するスパン・ラベルの判定
    1. 括弧、空白・記号、読み仮名等を含む表現
        - 通常は括弧内をスパンとするが、括弧や空白・記号等を分離できない場合はそれらも含め全体をスパンとしてラベルを付与する。
        - 例
            - 「「[蕎麦屋　たなか]」に行った」→ `FAC_NAME`
            - 「[磐座（いわくら）神社]」→ `FAC_NAME`
            - 「「[清明」碑]」→ `FAC_NAME`
    2. 複数の地域をまとめた表現
        - 別のスパンとしてそれぞれラベルを付与する。
        - 例
            - 「[名] [阪] 間」→ 「名」「阪」にそれぞれ `LOC_NAME`
    3. 施設種別名＋固有施設名
        - 全体をスパンとしてラベルを付与する。括弧を含む場合、基準 5-a に準じ、括弧もスパンに含める。
        - 例
            - 「[バス停「安倍文珠院」]」→ `FAC_NAME`
            - 「[居酒屋「和み」]」→ `FAC_NAME`
            - 「[JR奈良駅ビル「ビエラ奈良」]」→ `FAC_NAME`
            - 「[道の駅わっかない]」→ `FAC_NAME`
            - 「[はこだて海鮮市場本店]」（飲食店名＋店舗名）→ `FAC_NAME`
        
        c’ 全体施設名＋部分施設名
        
        - 例
            - 「江島神社　奥津宮」
            - 「三峯神社境内」
            - 「鶴ヶ城天守閣」
    4. 広域地名＋詳細地名・施設名
        - 方針1：全体で一つの固有名や通称名と判断できる場合は、全体をスパンとして `LOC_NAME` や `FAC_NAME` などのラベルを付与する。
            - 「福岡PayPayドーム」→ `FAC_NAME`
        - 方針2：全体で一つの固有名と判定すべきか迷う場合、以下の基準のようにする。
        1. NAME + NAME 型の場合、別々のスパンとしてそれぞれラベルを付与する。
            - 「[利尻礼文サロベツ国立公園] [こうほねの家]」→ `FAC_NAME` と `FAC_NAME`
        2. NAME + GENERAL 型の場合、全体をスパンとし、主辞（意味の中心）の単語に基づいて LOC か FAC かなどを決定する。
            - 「[奈良 公園]」→ `FAC_NAME`（奈良：`LOC_NAME` + 公園：`FAC_NOM` と分解可）
            - 「[木津城跡公園 駐車場]」→ `FAC_NAME`（木津川城跡公園：`FAC_NAME` + 駐車場：`FAC_NOM` と分解可）
        - 参考：`GENERAL` + `GENERAL` 型の場合、次項の該当例の一種となる。
    5. 名詞に修飾されている地名・施設名
        - 修飾している名詞を含め、全体をスパンとしてラベルを付与する。
        - 例
            - 「半独立丘陵」→ `LOC_NOM`
            - 「山頂駐車場」→ `FAC_NOM`
            - 「ラガウェイ社製風車」→ `FAC_NOM`
            - 「無料駐車場」→ `FAC_NOM`
    6. 名詞を修飾している地名・施設名
        - 方針1：移動・旅行・宿泊・居住などを表す（サ変）名詞が主辞の場合、地名・施設名部分のみをスパンとしてラベルを付与する。
            - 例：「[北海道]旅行」「[京都]観光」「[広島]在住」→ `LOC_NAME`
        - 方針2：その他の状況で地名・施設名でないものが主辞となる場合、ラベル付与対象外。
            - 例：「吉野葛」「三輪そうめん」「京茄子」「西ノ京ブレンド」「稚内土産」「フランス産」「北海道選奨土木遺産」「日本新三景」「太平洋戦争」「神社建築」「シティーライフ」
        - 方針3：イベント名に含まれる地名・施設名部分はスパンとしてラベルを付与する。
            - 例：「うまし[奈良]めぐり」「[岩内仙峡]もみじまつり」→ `LOC_NAME`
            - 例：「[四万十川]下り」→ `LINE_NAME`
            - 例：「[川]下り」→ `LINE_NOM`
    7. 方向・相対位置を表す接辞（接語）が付いた地名・施設名
        - 方針1：地名の前後に付く東西南北の接辞等はスパンに含めラベルを付与する。
            - 例：「[東東京]」（東京都の一部にあたる地域区分）、「[西東京]」（地域区分または市名）→ `LOC_NAME`
        - 方針2：その他の接辞（接語）はスパンに含めずにラベルを付与する。
            1. 施設名の後に付く方角：「[奈良駅]北」→ `FAC_NAME`
            2. 地域の部分：「[北海道]北部」「[東京]中央」「[本州]全域」「[本州]最南端」「[関西]中」→ `LOC_NAME`、「[国]内最北」→ `LOC_NOM`
            3. 詳細な場所をぼかす表現：「[大沼]周辺」→ `LOC_NOM`、「[奈良]らへん」「[東京]方面」「[東欧]圏」「[八王子]等」→ `LOC_NAME`
            4. 地域・施設を基準とした相対位置：「[店]内」→ `FAC_NOM`、「[道]内」「[奈良県]外」「[関西]以外」「[奈良駅]前」→ `LOC_NAME`
                - 「学園前」は「前」も含めて地名になっており、この場合は全体に付与する。
            5. 複数の地域・施設を基準とした位置関係や境界：「[名][阪]間」「[京都府]・[奈良県]境界」→ `LOC_NAME`、「[県]境」→ `LOC_NOM`
                - 「[支庁]界」 ：「支庁界」で地図記号が存在する概念だが、他の類例と同様に考えて、「支庁」にのみ付与する。
            6. その他、場所・施設を基準に詳細な位置や相対的な位置などを示す表現：「[日本海]沖」→ `LOC_NAME`、「[川]沿い」→ `LINE_NOM`
    8. 方向・相対位置以外の接辞（接語）が付いた地名・施設名
        - 接辞等の種類ごとに異なる扱いとする。
        - 方針1：次の場合、接辞等をスパンに含めてラベルを付与する。
            - 複数を表す接辞：「[風車群]」→ `FAC_NOM`
            - 属性・状態を詳細化する接辞：「[駅舎跡]」→ `FAC_NOM`、「[旧国鉄広尾線]」→ `LINE_NAME`、「[旧樺太]」→ `LOC_NAME`
        - 方針2：次の場合、接辞等をスパンに含めず、地名・施設名部分のみをスパンとしてラベルを付与する。
            - 発着を表す接辞：「[成田]発」「佐世保行き」→ `LOC_NAME`（文脈上、駅等の施設を表す場合は `FAC_NAME`）
        - 方針3：次の場合、ラベルを付与しない。
            - 形容詞的働きをするもの：「アジア的」「欧州型」「南米系」「神戸っぽい」「ウィーン風」
    9. 他カテゴリの固有表現に内包されている地名・施設名
        - 地名を構成要素に含んでいる場合であっても、他カテゴリの固有表現は付与対象外とする。
            - イベントに含まれる地名・施設名はスパン付与対象とする（参照：5.f.方針3）。
            - 作品名：「翔んで埼玉」「大阪LOVER」
            - 組織名：「日本言語学会」「東京事変」
6. **特殊な文脈・用法で言及される場所・施設名**に対するラベル付与・不付与
    1. 言語形式としての言及
        - 言語形式としての言及であっても、同時に特定の場所を指し得るため、ラベルを付与する。
        - 例
            - 「今『[奈良県]』と言いましたが」→ `LOC_NAME`
            - 「あそこの看板に『[駐車場]右折』って書いてあるよ」→ `FAC_NAME`
            - 「『[京都]』の『京』に『終わり』と書いて『[京終]（きょうばて）』です」→ `LOC_NAME`
    2. 否定のスコープ内での出現
        - 言語表現単独で地名・施設名にあたるものであれば、否定として述べられている場合であってもラベルを付与する。
        - 例
            - 「[丘]のない原野」 → `LOC_NOM`
            - 「[日本]ではないような景色」 → `LOC_NAME`
    3. 直喩、連想、比較対象としての言及
        - 方針1：言語表現単独で地名・施設名にあたるものであれば、比喩や比較対象として述べられている場合であっても、ラベルを付与する。
            - 比較対象・連想の例
                - 「[線路]並にどこまでも続く道」
                - 「[天に続く道]を連想しました」
            - 直喩の例
                - 「[銭湯]のような雰囲気」
                - 「[サグラダ・ファミリア]のようでした」
        - 方針2：「日本一」「日本最大級」など、主辞が地名・施設名でないような表現である場合は付与対象としない。
            - ただし、「[日本]で最長の…」などと書かれている場合には付与する。
    4. メトニミー、シネクドキとしての言及
        - 文脈から場所・施設を指していると判断できる場合はラベルを付与し、それらを指していないと考えられる場合は付与しない。
        - メトニミー（換喩）は、近接性に基づく比喩と説明され、「鍋（を食べる）」で「鍋の中の具」を意味する、「ホワイトハウス（が発表）」で「アメリカ政府」を意味するなど、「容器-中身」や「場所-組織」のようなパターンがある。なお、語義として定着し、多義語の語義の一つとみるかメトニミーとみるか自明でない場合がある。
        - シネクドキ（提喩）は、上位カテゴリで下位カテゴリを意味する、または下位カテゴリで上位カテゴリを意味するもので、上位カテゴリで下位カテゴリを意味する例には「花（見）」→「桜」、下位カテゴリで上位カテゴリを意味する例には「ご飯」→「食べ物一般」や、「タッパー」（固有名・商標）→「プラスチック製密閉容器一般」などがある。
        - メトニミーの例
            - 「温泉」の基本的な語義は「地中から湧き出す温水」だが、「温泉を貯めている浴槽・浴場という温泉設備」や、「そうした浴場がある温泉施設」を指し得る。
                - 「観光案内所で[温泉]を紹介してもらいました。」
                → 独立した温泉施設を指す。`FAC_NOM` を付与する。
                - 「ホテルには[温泉]もあります」
                → ホテル内の温泉設備を指す。6. 施設部分名・施設内施設の方針に従い、ラベルを付与しない。
                - 「ホテルには[ラジウム温泉]の大浴場がありました」
                → 温泉のお湯自体（の性質）を指す。付与しない。
            - 「滝」は「垂直に近い水の流れ」と「そのような流れがある場所」という意味がある。
                - 「[男滝]と[女滝]とあわせて[夫婦滝]とも呼ばれます」
                → 固有名が付いた地形・場所としての滝を指す。いずれも`LOC_NAME`を付与する。
                - 「層雲峡の力強い[滝]の音を聞いていると」
                → 層雲峡を流れる水の流れという意味合いが強く、ラベルを付与しない。
            - 飲食店・メニューの間のメトニミー
                - 「気になってた[ラーメン]行った」
                    - 「ラーメンを食べに行った」または「ラーメン屋に行った」のどちらかを意味すると考えられる。移動動詞の項となっていることや、文脈を考慮し、「ラーメン」に `FAC_GEN` を付与する。
                - 「スタバ飲んだ」
                    - 「[スタバ]のドリンクを飲んだ」の意味と考えられ、スタバの店舗に行ったかは不明。飲食に関する動詞の項となっていることや、文脈を考慮し、「スタバ」にはラベルを付与しない。
        - シネクドキの例
            - 上位カテゴリで下位カテゴリを意味する例は普遍的で、特に注意すべき点はないと思われる。
7. **現存・実在しない場所・施設の名前**に対するラベル付与・不付与
    1. 過去に存在した地名・施設名は付与対象
        - 「駅舎跡」「廃駅」→ `FAC_NOM`、「廃線」→ `LINE_NOM`
            - 現在は元の機能を有していないことが明示されている表現
        - 「大森区」→ `LOC_NAME`
            - 現在は、大森区＋蒲田区→大田区
    2. 未来に創設予定の地名・施設名は付与対象
    3.  作品・神話中の想像上・架空の地名・施設名には**付与しない**
8. その他の注意事項
    1. 1文内または複数文内に、同一実体を指す言及が複数回現れる場合、すべての言及にラベルを付与する。
        - 例：「A=B」型の表現（等価、同格）
            - 「[仏沼]は青森県唯一の[ラムサール条約指定地]」
            - 「[恋人の聖地]として認定された[竹田城跡]」
            - 「[国立公園]の[釧路湿原]」
